One Letter: Coffee or Tea. The entry is exactly one letter, A for coffee or
B for tea, and nothing else — no word, no explanation, no punctuation. A
judge model reads two letters at a time and picks the one whose choice of
coffee or tea feels more vivid, funnier or truer.

This entry picks **A — coffee**. Of the two drinks, coffee is the bolder,
more vivid stance: dark, hot, aromatic, the drink that wakes you up and gets
you going. Against the judge's brief, coffee lands as the fuller, more alive
answer — the stronger aroma, the bigger jolt, the louder ritual. Tea is the
quieter cup; coffee is the one you can taste from the next room.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That writes exactly one byte, `A`, to `out/entry.txt`. `main.ts` (Node 22,
standard library only, no network) does nothing else, and it checks its own
output: if the file it wrote is not exactly `A`, it fails loudly instead of
handing the house a bad entry.
